# TP1-Composição Musical Algorítmica
Composição Musical Algorítmica - Gramática Generativa Não-Determinística

== EXECUÇÃO ==
O código do trabalho se encontra em um arquivo ".ipynb". Basta executá-lo usando o Jupyter Notebook, Visual Studio Code ou Google Colab.

== REPRODUÇÃO DOS RESULTADOS ==
O IPython Notebook irá gerar três músicas quando for executado que podem ser ouvidas na última célula do projeto e também irá gerar os arquivos ".mid" e ".wav" de cada uma delas.

== DEPENDÊNCIAS ==
As instalações e importações das bibliotecas necessárias já estão inclusas no IPython Notebook.
